「Claude Code（クロードコード）を使ってみたいけど、インストール方法や始め方が分からない」という人に向けて、**Claude Code の使い方** を初心者向けにまとめました。

## Claude Code とは？ 何ができるの？ {#what-is}

Claude Code は、Anthropic 社の AI「Claude」を、ターミナル（文字で PC を操作する画面）から使えるようにした **AI コーディングツール** です。

### チャットの Claude との違い {#vs-chat}

ブラウザで使うチャットの Claude は、答えやコードを画面に表示してくれます。それを自分でコピーして使う形です。
Claude Code は、**AI が実際に手を動かせる** のが一番の違いです。

- フォルダの中のファイルを読んで、内容を理解する
- 新しいファイルを作る・既存のファイルを書き換える
- コマンドを実行して、結果を確かめる
- うまくいかなければ、エラーを読んで直す

たとえば「このフォルダにブログのひな形を作って」と頼むと、必要なファイルを一式作ってくれます。
ファイルの変更やコマンドの実行の前には、基本的に **許可を求めてくる** ので、知らないうちに勝手なことをされる心配は小さくなっています。

### 実際に使ってみて役立ったこと {#my-experience}

私自身、ゲームエンジンはほぼ初心者ですが、Claude Code と一緒に **Unreal Engine で剣で戦うアクションゲーム** を作ったり、**自分の PC で動く画像生成 AI の環境** を作ったりしてきました。
エンジンの設定やインストールでつまずいたとき、エラーを読んで原因を調べ、直すところまで一緒にやってくれるのが一番助かっています。
（それぞれの詳しい話は、別の記事で紹介する予定です）

## Claude Code の料金と必要なもの {#price}

- **Claude の有料プラン（Pro / Max など）か、API（Anthropic Console）のアカウント**：無料プランだけでは使えません。料金は [Claude の料金ページ](https://claude.com/pricing) で確認してください。
- **パソコン**：Windows / Mac / Linux（この記事では Windows で説明します）。Windows は 10（1809 以降）か 11、メモリは 4GB 以上が目安です
- **インターネット接続**
- **（Windows で推奨）[Git for Windows](https://git-scm.com/downloads/win)**：入れておくと、Claude Code が Windows 上でより多くのコマンドを使えるようになります。なくても PowerShell で動きます。

プログラミングの知識は、最初はなくても大丈夫です。
ただし「何を作りたいか」「どうなったら完成か」を日本語で説明できることが大事です（[うまく使うコツ](#tips) で説明します）。

## Claude Code のインストール方法（Windows） {#install-windows}

### 手順1：PowerShell を開く {#step1}

スタートメニューで「PowerShell」と検索して開きます。文字を打ち込んで PC を操作する画面です。

### 手順2：インストールコマンドを実行する {#step2}

[公式のセットアップページ](https://code.claude.com/docs/ja/setup) に載っているインストール用のコマンドを、PowerShell に貼り付けて Enter を押します。

```powershell
irm https://claude.ai/install.ps1 | iex
```

> インターネットから取ってきたコマンドを実行するときは、必ず **公式サイトに載っているものか** を確認してから使いましょう。

### 手順3：インストールできたか確認する {#step3}

インストールが終わったら **PowerShell を一度閉じて開き直し**、次のコマンドを実行します。バージョン番号が表示されれば成功です。

```powershell
claude --version
```

### Mac・Linux の場合 {#install-mac-linux}

Mac や Linux では、ターミナルで次のコマンドを実行します。

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

## Claude Code の始め方：最初の起動とログイン {#first-launch}

Claude Code は「起動したフォルダ」を作業場所にします。まず作業用のフォルダを作り、そこに移動してから `claude` と入力して起動します。

```powershell
mkdir $HOME\Desktop\test-project
cd $HOME\Desktop\test-project
claude
```

初回はログインを求められるので、画面の案内に従ってブラウザで Claude のアカウントにログインします。

## Claude Code の基本的な使い方 {#basic-usage}

### 日本語で頼んでみる {#ask-in-japanese}

起動すると、文字を入力できる状態になります。**日本語で普通に話しかけて大丈夫** です。

```text
このフォルダに、自己紹介を書いた簡単な HTML ページを作ってください。
名前は「テスト太郎」、趣味はゲームです。
```

Claude Code は作業内容を説明しながら、ファイルを作る前に許可を求めてきます。内容を見て問題なければ許可しましょう。
できあがった HTML ファイルをダブルクリックすれば、ブラウザでページを確認できます。

### 覚えておくと便利なコマンド {#commands}

| 操作 | 意味 |
|---|---|
| `/help` | 使えるコマンドの一覧を表示 |
| `/clear` | 会話をリセットして、新しい話題を始める |
| `/compact` | 長くなった会話を要約して、続きを軽くする |
| `/init` | CLAUDE.md（後で説明）のひな形を作る |
| `Esc` | AI の作業を途中で止める |

## Claude Code をうまく使う5つのコツ {#tips}

使ってみて分かった、失敗しにくい頼み方です。

### 1. ゴールを具体的に書く {#tip1}

「いい感じにして」よりも、「**何を・どうなったら完成か**」を書くほうが、ずっと良い結果になります。

- ✕「ゲームを作って」
- ○「ブラウザで遊べる、矢印キーで動く四角がコインを集める簡単なゲームを作って。コインを10個集めたらクリアと表示する」

### 2. 小さく分けて頼む {#tip2}

一度に全部を頼むより、「まず画面を出す」→「次に動かす」→「次に得点を付ける」のように、**1つずつ確かめながら** 進めるほうが失敗が少なくなります。

### 3. 「確かめて」とお願いする {#tip3}

「作ったら、実際に動かして確認してから報告して」と付け加えると、作りっぱなしではなく動作確認までしてくれることが多くなります。

### 4. 会話が長くなったら整理する {#tip4}

1つの会話が長くなりすぎると、前の内容を忘れやすくなります。作業の区切りで `/compact`（要約して続ける）や `/clear`（リセット）を使いましょう。

### 5. プロジェクトのルールは CLAUDE.md に書く {#tip5-claude-md}

作業フォルダに `CLAUDE.md` というファイルを置くと、Claude Code は起動するたびにそれを読みます。
「日本語で説明して」「初心者なので専門用語は説明して」といった、毎回伝えたいことを書いておくと便利です。
`/init` と入力すると、ひな形を作ってくれます。

私の場合は、「実装しただけで完了にせず、実際に動かして確かめてから報告する」「報告は初心者にも分かる言葉で」といったルールを書いています。
さらに、ゲーム制作や画像生成の環境づくりでハマった原因と解決法を **ノウハウ集** としてファイルに残し、CLAUDE.md から「作業の前に読んで」と指示しています。
こうしておくと、別のプロジェクトでも同じ失敗を繰り返しにくくなりました。

## よくあるエラーと対処法 {#errors}

### 「'irm' は認識されていません」と表示される {#error-irm}

PowerShell ではなく **コマンドプロンプト** で実行しています。スタートメニューから PowerShell を開き直して、もう一度実行してください。

### 「'claude' は認識されていません」と表示される {#error-claude}

インストール直後は、開いていた PowerShell が新しいコマンドをまだ知りません。**PowerShell を閉じて開き直して** から、もう一度 `claude` と入力してください。

## よくある質問 {#faq}

### Claude Code は無料で使えますか？ {#faq-free}

無料プランだけでは使えません。Claude の有料プラン（Pro / Max など）か、API（Anthropic Console）のアカウントが必要です。

### 日本語で使えますか？ {#faq-japanese}

使えます。頼むときも、返事を受け取るときも日本語で大丈夫です。CLAUDE.md に「日本語で説明して」と書いておくと確実です。

### プログラミング初心者でも使えますか？ {#faq-beginner}

使えます。私もゲームエンジン初心者の状態から使い始めました。ただし、AI が何をしようとしているかを確認して許可するのは自分なので、分からないことは「これは何をするコマンド？」と遠慮なく聞きましょう。

### Mac でも使えますか？ {#faq-mac}

使えます。[Mac・Linux の場合](#install-mac-linux) のコマンドでインストールできます。

## まとめ {#summary}

- Claude Code は、AI が PC のフォルダの中で実際に作業してくれる AI コーディングツール
- 使うには Claude の有料プランか API のアカウントが必要
- Windows では PowerShell で `irm https://claude.ai/install.ps1 | iex` を実行してインストール
- 作業フォルダで `claude` と入力して起動し、日本語で頼むだけ
- 頼むときは「ゴールを具体的に」「小さく分けて」「確かめて、と添える」
