「AI にコードを書いてもらう」と聞くと、チャット画面にコードを貼り付けて……という使い方を想像するかもしれません。
**Claude Code** はそこから一歩進んで、AI が **自分の PC のフォルダの中で、ファイルを読んだり、作ったり、コマンドを実行したり** してくれるツールです。

この記事では、プログラミングやゲームエンジンの初心者でも使い始められるように、次の順番で説明します。

1. Claude Code って何ができるの？
2. 使うのに必要なもの
3. インストールと最初の起動（Windows）
4. 最初のお願いをしてみる
5. うまく頼むためのコツ

> ツールの仕様や料金は変わることがあります。最新の情報は [公式ドキュメント](https://code.claude.com/docs/ja/overview) も確認してください。

## 1. Claude Code って何ができるの？

Claude Code は、Anthropic 社の AI「Claude」を、ターミナル（文字で PC を操作する黒い画面）から使えるようにしたツールです。
普通のチャット AI との一番の違いは、**AI が実際に手を動かせる** ことです。

- フォルダの中のファイルを読んで、内容を理解する
- 新しいファイルを作る・既存のファイルを書き換える
- コマンドを実行して、結果を確かめる
- うまくいかなければ、エラーを読んで直す

たとえば「このフォルダにブログのひな形を作って」と頼むと、必要なファイルを一式作ってくれます。
ファイルの変更やコマンドの実行の前には、基本的に **許可を求めてくる** ので、知らないうちに勝手なことをされる心配は小さくなっています。

私自身、ゲームエンジンはほぼ初心者ですが、Claude Code と一緒に **Unreal Engine で剣で戦うアクションゲーム** を作ったり、**自分の PC で動く画像生成 AI の環境** を作ったりしてきました。
エンジンの設定やインストールでつまずいたとき、エラーを読んで原因を調べ、直すところまで一緒にやってくれるのが一番助かっています。
（それぞれの詳しい話は、別の記事で紹介する予定です）

## 2. 使うのに必要なもの

- **パソコン**：Windows / Mac / Linux（この記事では Windows で説明します）
- **Claude の有料プラン（Pro / Max など）か、API（Anthropic Console）のアカウント**：無料プランだけでは使えません。料金は公式サイトで確認してください。
- **インターネット接続**
- **（推奨）[Git for Windows](https://git-scm.com/downloads/win)**：入れておくと、Claude Code が Windows 上でより多くのコマンドを使えるようになります。なくても PowerShell で動きます。

プログラミングの知識は、最初はなくても大丈夫です。
ただし「何を作りたいか」「どうなったら完成か」を日本語で説明できることが大事です（後で説明します）。

## 3. インストールと最初の起動（Windows）

### 3-1. PowerShell を開く

スタートメニューで「PowerShell」と検索して開きます。文字を打ち込んで PC を操作する画面です。

### 3-2. インストールコマンドを実行する

公式ドキュメントに載っているインストール用のコマンドを、PowerShell に貼り付けて Enter を押します。
執筆時点では、Windows 向けに次のようなコマンドが案内されています。

```powershell
irm https://claude.ai/install.ps1 | iex
```

> インターネットから取ってきたコマンドを実行するときは、必ず **公式サイトに載っているものか** を確認してから使いましょう。
>
> 「'irm' は認識されていません」というエラーが出たら、PowerShell ではなくコマンドプロンプトで実行しています。PowerShell を開き直してください。

インストールが終わったら **PowerShell を一度閉じて開き直し**、次のコマンドでバージョンが表示されれば成功です。

```powershell
claude --version
```

### 3-3. 作業用のフォルダで起動する

Claude Code は「起動したフォルダ」を作業場所にします。まず作業用のフォルダを作り、そこに移動してから起動します。

```powershell
mkdir $HOME\Desktop\test-project
cd $HOME\Desktop\test-project
claude
```

初回はログインを求められるので、画面の案内に従ってブラウザで Claude のアカウントにログインします。

## 4. 最初のお願いをしてみる

起動すると、文字を入力できる状態になります。普通に日本語で話しかけて大丈夫です。

```text
このフォルダに、自己紹介を書いた簡単な HTML ページを作ってください。
名前は「テスト太郎」、趣味はゲームです。
```

Claude Code は作業内容を説明しながら、ファイルを作る前に許可を求めてきます。内容を見て問題なければ許可しましょう。
できあがった HTML ファイルをダブルクリックすれば、ブラウザでページを確認できます。

### 覚えておくと便利な操作

| 操作 | 意味 |
|---|---|
| `/help` | 使えるコマンドの一覧を表示 |
| `/clear` | 会話をリセットして、新しい話題を始める |
| `/compact` | 長くなった会話を要約して、続きを軽くする |
| `Esc` | AI の作業を途中で止める |

## 5. うまく頼むためのコツ

使ってみて分かった、失敗しにくい頼み方です。

### ゴールを具体的に書く

「いい感じにして」よりも、「**何を・どうなったら完成か**」を書くほうが、ずっと良い結果になります。

- ✕「ゲームを作って」
- ○「ブラウザで遊べる、矢印キーで動く四角がコインを集める簡単なゲームを作って。コインを10個集めたらクリアと表示する」

### 小さく分けて頼む

一度に全部を頼むより、「まず画面を出す」→「次に動かす」→「次に得点を付ける」のように、**1つずつ確かめながら** 進めるほうが失敗が少なくなります。

### 「確かめて」とお願いする

「作ったら、実際に動かして確認してから報告して」と付け加えると、作りっぱなしではなく動作確認までしてくれることが多くなります。

### プロジェクトのルールは CLAUDE.md に書く

作業フォルダに `CLAUDE.md` というファイルを置くと、Claude Code は起動するたびにそれを読みます。
「日本語で説明して」「初心者なので専門用語は説明して」といった、毎回伝えたいことを書いておくと便利です。
`/init` と入力すると、ひな形を作ってくれます。

私の場合は、「実装しただけで完了にせず、実際に動かして確かめてから報告する」「報告は初心者にも分かる言葉で」といったルールを書いています。
さらに、ゲーム制作や画像生成の環境づくりでハマった原因と解決法を **ノウハウ集** としてファイルに残し、CLAUDE.md から「作業の前に読んで」と指示しています。
こうしておくと、別のプロジェクトでも同じ失敗を繰り返しにくくなりました。

## まとめ

- Claude Code は、AI が PC のフォルダの中で実際に作業してくれるツール
- 使うには Claude の有料プランか API 契約が必要
- インストール後、作業フォルダで `claude` と入力して起動
- 頼むときは「ゴールを具体的に」「小さく分けて」「確かめて、と添える」
