## 作ったもの：GitHub Pages＋Jekyll の無料ブログ {#what-i-made}

- **GitHub Pages**：GitHub が無料で提供している、Web サイトを公開できるサービスです。`ユーザー名.github.io` という URL でサイトを公開できます。
- **Jekyll（ジキル）**：Markdown（`#` で見出し、`-` で箇条書きを書くような簡単な書き方）で書いた文章を、Web ページに変換してくれる仕組みです。GitHub Pages に最初から組み込まれています。

つまり、**記事を Markdown で書いて GitHub に送るだけで、自動でブログのページになって公開される** という形です。サーバー代はかかりません。

### かかった費用 {#cost}

ブログ自体は **0 円** です。GitHub のアカウントも、GitHub Pages も、Google Search Console も無料で使えます。

ただし Claude Code を使うには、Claude の有料プランなどが必要です（詳しくは [前の記事]({{ "/posts/claude-code-getting-started/" | relative_url }}#price) を見てください）。

## 全体の流れと、AI と自分の役割分担 {#overview}

作業はおおまかに次の順番で進めました。

| 手順 | やったこと | 担当 |
|---|---|---|
| 1 | GitHub にリポジトリ（保存場所）を作る | 自分 |
| 2 | ブログに必要なファイル一式を作る | Claude Code |
| 3 | 最初の記事を書き、検索向けに整える | Claude Code（体験談は自分） |
| 4 | GitHub に送って公開する | Claude Code（初回ログインだけ自分） |
| 5 | 公開されたページを確かめる | Claude Code |
| 6 | Google Search Console に登録する | 一緒に（画面の操作は自分） |

**ファイル作りや確認作業はほとんど Claude Code** がやってくれました。

自分でやったのは、GitHub や Google の画面での操作と、記事に入れる体験談、そして「どうしたいか」を決めることです。

## 手順1：GitHub でリポジトリを作る（自分） {#step1-repository}

GitHub にログインして、新しいリポジトリを作ります。ここだけは Web の画面での操作なので、自分でやりました。

- リポジトリ名は **`ユーザー名.github.io`**（例：ユーザー名が `taro` なら `taro.github.io`）
- 公開設定は **Public**

この名前にすると、`https://ユーザー名.github.io` というアドレスでサイトが公開されます。

## 手順2：Claude Code にブログのひな形を作ってもらう {#step2-files}

ブログ用のフォルダで Claude Code を起動して、日本語でこんなふうに頼みました。

```text
GitHub Pages で記事を公開して、広告収入を得たいと思っています。
最初の記事を公開するまでの手順を教えてほしいのと、その手助けをしてほしいです。
```

Claude Code は最初に「GitHub アカウントはあるか」「記事のテーマは何か」「どの作り方にするか」を選択肢で聞いてきました。答えると、次のファイルを作ってくれました。

| ファイル | 役割 |
|---|---|
| `_config.yml` | ブログ名・説明・テーマなど、サイト全体の設定 |
| `index.md` | トップページ（記事の一覧） |
| `about.md` | 運営者の紹介ページ |
| `privacy.md` | プライバシーポリシー・免責事項 |
| `_posts/` | 記事を入れるフォルダ |

デザインは Jekyll の標準テーマ「minima」を使っています。

### 広告を見すえた準備もしてくれた {#prepare-ads}

「広告収入を得たい」と最初に伝えたので、Claude Code は次のような準備もしてくれました。

- **プライバシーポリシー** のページ（広告やアクセス解析を使うサイトでは必要になります）
- 広告の審査に通ったら、**設定ファイルに 1 行書くだけで広告のコードが入る仕組み**
- 検索エンジン向けの情報（ページの説明文など）を自動で出すプラグイン、サイトマップ、RSS の設定

## 手順3：最初の記事を書き、検索向けに整える {#step3-article}

最初の記事のテーマは「Claude Code の使い方」にしました。Claude Code が下書きを作り、私は **自分の体験** を伝えて書き足してもらいました。

その後、「検索でヒットしやすい内容にしてほしい」と頼むと、次のように直してくれました。

- タイトルの前半に、検索されやすい言葉（「Claude Code」「使い方」「インストール」など）を入れる
- 見出しにも、検索されそうな言葉を入れる
- 目次・よくあるエラー・よくある質問（FAQ）の見出しを足す
- 検索結果に出る説明文（description）を 100〜120 文字ほどで書く

> AI が書いただけの記事は、どこかで見たような内容になりがちです。**自分が実際にやったこと・困ったこと** を入れると、記事の価値が上がります。

## 手順4：GitHub に送って公開する {#step4-publish}

ファイルができたら、Claude Code が Git（ファイルの変更を記録して GitHub に送る道具）で記録を作り、GitHub に送ります。

ここで 1 回だけつまずきました。**初めて GitHub に送るときは、ログインが必要** で、Claude Code からはそのログイン画面を操作できなかったのです。

そこで、Claude Code の入力欄で先頭に `!` を付けて、送信のコマンドを **自分で** 実行しました。

```text
! git push -u origin main
```

`!` を付けると、AI を通さずに、そのコマンドをその場で直接実行できます（Claude Code の「bash モード」）。画面の案内に従って GitHub にログインすると、送信が成功しました。

2 回目からは、Claude Code だけで送れるようになりました。送ってから 1〜2 分ほどで、ブログが公開されました。

## 手順5：公開されたページを確かめる {#step5-check}

公開できたら、Claude Code が実際のページを読み込んで確かめてくれました。

- 記事のページ、トップページ、運営者紹介、プライバシーポリシーが表示されるか
- 目次やページ内のリンクが動くか
- サイトマップ（`sitemap.xml`）が出ているか

さらに、別の AI（サブエージェント）に記事を **チェック（監査）** させて、見つかった問題を直し、もう一度公開し直してくれました。

## 手順6：Google Search Console に登録する {#step6-search-console}

**Google Search Console** は、自分のサイトが Google 検索でどう見えているかを確認できる無料のツールです。登録すると、「ここにサイトがあるよ」と Google に知らせることができます。

### 1. プロパティを追加する {#gsc-add}

[Google Search Console](https://search.google.com/search-console) を開き、「プロパティを追加」で **「URL プレフィックス」** を選び、`https://ユーザー名.github.io/` を入力します。

（もう一つの「ドメイン」は、DNS という設定を変える必要があり、github.io では使えません）

### 2. 所有権を確認する（HTML タグ） {#gsc-verify}

「このサイトの持ち主です」と証明するために、確認方法で **「HTML タグ」** を選びます。表示された `<meta name="google-site-verification" content="……">` のタグを Claude Code に渡すと、`_config.yml` に次のように書いてくれました。

```yaml
webmaster_verifications:
  google: （content の中の文字列）
```

これだけで、ブログのすべてのページに確認用のタグが入ります。GitHub に送って 1 分ほど待ち、Search Console の「確認」ボタンを押すと、所有権の確認が完了しました。

### 3. サイトマップを送信する {#gsc-sitemap}

左のメニューの「サイトマップ」を開き、`sitemap.xml` と入力して送信します。サイトマップは、ブログのページの一覧を Google に渡すためのファイルで、Jekyll のプラグインが自動で作ってくれます。

> 登録してすぐに検索に出るわけではありません。検索結果に表示されるまで、数日〜数週間ほどかかることがあります（もっとかかることもあります）。

## つまずきやすいポイント {#pitfalls}

今回の作業の中で実際に出てきた、初心者が気をつけたいポイントです。

### 記事の日付を「未来」にすると公開されない {#pitfall-future-date}

GitHub Pages は、**日時が未来になっている記事を、何も言わずに公開しません**。エラーも出ないので気づきにくいです。

しかも、その時刻を過ぎても自動では公開されず、次に GitHub に送ったときに初めて公開されます。記事の日付は、公開する時刻より前にしておきましょう。

### 見出しには英語の ID を付けておくと安心 {#pitfall-heading-id}

日本語の見出しにも、リンク用の名前（ID）は自動で付きます。ただし URL にすると `%E3%81...` のように長く読みにくくなり、見出しの文を変えるとリンクが切れてしまいます。

見出しの後ろに英語の ID を付けておくと、短くて変わらないリンクになります。

```markdown
## よくある質問 {#faq}
```

### 記事の URL の形は最初に決める {#pitfall-permalink}

記事の URL の形は、公開する前に決めておきましょう。公開後に変えると、検索の評価を引き継ぎにくくなり、古いリンクも切れてしまいます。

このブログでは `/posts/ファイル名から日付を除いた部分/` という短い形にしました。

### github.io のままだと AdSense の申請が難しい {#pitfall-adsense}

Google AdSense は、**自分で持っているドメイン** で申請するのが基本です。`ユーザー名.github.io` のままでは申請できない可能性が高く、独自ドメイン（年に千数百円ほど〜。2 年目からの更新料にも注意）が必要になりそうです。

私はまだ申請していません。まずは記事を増やしてから考える予定です。

## やってみた感想 {#impressions}

正直に言うと、**自分が何をしたかよりも、Claude Code が何をしてくれたかのほうがずっと多い** です。ファイル作り、設定、公開、確認まで進めてくれて、私がやったのは GitHub と Google の画面での操作と、「こうしたい」を伝えることくらいでした。

一方で、AI に任せきりにはできない部分もありました。

- どんなブログにするか、何を書くかを決めること
- 記事に入れる自分の体験
- ログインや、Google の画面での操作

それでも、「ブログってどう作るの？」という状態から 10 分ほどで公開まで行けたのは、一人では無理だったと思います。

## よくある質問 {#faq}

### 本当に無料でブログを作れますか？ {#faq-free}

GitHub Pages と Google Search Console は無料です。ブログ自体には費用がかかりません。Claude Code を使う場合は、Claude の有料プランなどが必要です。独自ドメインを使う場合は、ドメイン代がかかります。

### プログラミングの知識がなくても作れますか？ {#faq-no-programming}

私はほぼ知識がない状態で作れました。ファイルの中身は Claude Code が書いてくれます。ただし、何をしようとしているか分からないときは「これは何をしているの？」と聞きながら進めるのがおすすめです。

### 記事はどうやって追加するのですか？ {#faq-add-post}

`_posts` フォルダに `2026-10-28-my-first-post.md` のような名前で Markdown ファイルを置き、GitHub に送ります。ファイル名はそのまま URL になるので、英数字にするのがおすすめです。Claude Code に「新しい記事を追加して公開して」と頼めば、そこまでやってくれます。

### Search Console に登録すると、すぐ検索に出ますか？ {#faq-index-time}

すぐには出ません。数日〜数週間ほどかかることがあります。Search Console の「ページ」で、登録されたかどうかを確認できます。

## まとめ {#summary}

- GitHub Pages＋Jekyll なら、**無料** でブログを作って公開できる
- ファイル作り・設定・公開・確認は、**Claude Code に日本語で頼むだけ** でほぼ進む
- 自分でやるのは、GitHub と Google の画面での操作、最初のログイン、記事に入れる体験談
- 公開したら **Google Search Console** に登録して、サイトマップを送る
- 記事の日付・見出しの ID・URL の形は、最初に気をつけておく

次は、Claude Code と一緒に作っているゲームや画像生成の環境について、詳しく書いていく予定です。
