ブログを公開したあと、ふと「この記事、何人くらい読んでくれているんだろう？」と思いました。ところが調べてみると、**このブログ（GitHub Pages）には閲覧数を見る機能がそもそも無い** ことが分かりました。そんなことも知らなかったのです。

閲覧数が分からないと、どの記事が読まれているのか、次に何を書けばいいのか、ブログの方向性を考えられません。そこで、無料のアクセス解析ツール **Google アナリティクス** を入れることにしました。

この記事では、そのときの登録の手順と、最低限知っておきたい用語を、初心者の私がつまずいた所も含めてまとめます。

**この記事で分かること**

- Google アナリティクスで何が分かるのか（Search Console との違い）
- 登録の手順と、分かりにくい用語（アカウント・プロパティ・測定 ID）
- ブログに計測コードを入れる方法と、計測できているかの確かめ方
- ユーザー・セッション・表示回数など、レポートの基本用語

## Google アナリティクスとは {#what-is-ga}

**Google アナリティクス**（よく「GA」「GA4」と略されます）は、Google が提供している **アクセス解析ツール** です。ブログに専用のコードを入れておくと、次のようなことが分かります。

- 何人がブログを見に来たか
- どの記事がよく読まれているか
- どこから来たか（Google 検索、SNS、ほかのサイトのリンクなど）
- どれくらいの時間、読んでくれたか

通常版は **無料** で使えます（大企業向けの有料版「Google アナリティクス 360」もありますが、個人のブログには必要ありません）。

「GA4」は今の Google アナリティクスの名前です。以前の「ユニバーサル アナリティクス」は 2023年7月1日にデータの処理が終わっているので、これから始めるなら GA4 一択です。

### Search Console との違い {#vs-search-console}

ブログを検索に載せるために登録する **Google Search Console** にも、アクセスに関する数字が出ます。ただし、見ているものが違います。

| ツール | 分かること |
|---|---|
| Google Search Console | **Google 検索の結果** に何回表示され、何回クリックされたか。どんな言葉で検索されたか |
| Google アナリティクス | **ブログに来た人** 全体の動き。検索以外（SNS・ブックマークなど）から来た人も含む。どの記事を読み、どれくらい滞在したか |

ざっくり言うと、**Search Console は「ブログに来る前（検索結果）」、アナリティクスは「ブログに来た後」** を見るツールです。両方とも無料なので、両方入れておくのがおすすめです。

Search Console の登録方法は [Claude Codeでブログを作る方法]({{ "/posts/claude-code-github-pages-blog/" | relative_url }}#step6-search-console) で紹介しています。

## 先に知っておきたい4つの言葉 {#structure}

登録の画面は **専門用語が多くて分かりにくかった** というのが正直な感想です。先に次の 4 つだけ押さえておくと、だいぶ迷わなくなります。

| 言葉 | 意味 | このブログの場合 |
|---|---|---|
| アカウント | いちばん大きな入れ物。ふつうは 1 人（1 つの事業）に 1 つ | 「カステラ」 |
| プロパティ | 1 つのサイト（またはアプリ）のデータをまとめる単位。時間帯や通貨もここで決める | 「AI開発メモ」 |
| データストリーム | データの入り口。ウェブサイト・iOS アプリ・Android アプリから選ぶ | ブログの URL |
| 測定 ID | ウェブのデータストリームに付く番号。`G-` で始まる | `G-` で始まる 10 文字ほど |

**アカウント ＞ プロパティ ＞ データストリーム** という入れ子になっていて、ブログに入れるのは最後の **測定 ID** です。ブログが 1 つだけなら、それぞれ 1 つずつ作れば大丈夫です。

## 登録の手順 {#sign-up}

Google アカウントがあれば、数分で終わります。画面の文言は、日本語表示のときのものです。

### 1. 測定を開始する {#step1-start}

[Google アナリティクス](https://analytics.google.com/) を開き、Google アカウントでログインして **「測定を開始」** を押します。

### 2. アカウントを作る {#step2-account}

**アカウント名** を入れます。自分で分かる名前なら何でもかまいません。その下のデータ共有の設定は、そのままで大丈夫です。「次へ」を押します。

### 3. プロパティを作る {#step3-property}

- **プロパティ名**：ブログの名前など
- **レポートのタイムゾーン**：日本
- **通貨**：日本円

を選んで「次へ」を押します。タイムゾーンを日本にしておかないと、「今日のアクセス」の区切りがずれてしまいます。

### 4. ビジネスの説明と目標を選ぶ {#step4-business}

業種や規模、利用目的を聞かれます。個人のブログなら、近いものを選べば大丈夫です。あとのレポートの並びが少し変わるくらいなので、深く悩まなくてかまいません。「作成」を押し、国を「日本」にして利用規約に同意します。

### 5. ウェブのデータストリームを作る {#step5-stream}

「データ収集を開始」の画面で **「ウェブ」** を選び、

- **ウェブサイトの URL**：ブログの URL（`https://` は左の欄で選ぶので、それ以降だけ）
- **ストリーム名**：ブログの名前など

を入れて **「作成して続行」** を押します。「拡張計測機能」は最初からオンになっていて、そのままで大丈夫です。

### 6. 測定 ID（またはタグ）を控える {#step6-measurement-id}

最後に、**測定 ID**（`G-XXXXXXXXXX`）や、ブログに貼るための **計測コード（タグ）** が表示されます。計測コードは、次のような形をしています。

```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());

  gtag('config', 'G-XXXXXXXXXX');
</script>
```

私はここで **何を貼ればいいのか迷いました**。結局、このコードを丸ごとコピーして Claude Code に「これ？」と聞きました。中に書かれている `G-` で始まる部分が測定 ID で、ブログに必要なのは実質この番号だけでした。

測定 ID は、あとからでも **管理（左下の歯車）→ データストリーム → 作ったストリーム** で確認できます。なお、測定 ID は公開ページの中に書かれるものなので、人に見られても問題ありません。

## ブログに計測コードを入れる {#install-tag}

計測コードは、ブログの **すべてのページの `<head>`**（ページの見えない設定部分）に入れます。入れ方はブログの種類によって違います。

- **WordPress など**：Google アナリティクス用のプラグインや、テーマの設定欄に測定 ID を入れるのが一般的です。
- **このブログ（GitHub Pages＋Jekyll）**：テーマの `<head>` のファイルに、上の計測コードを書き足します。

このブログでは、計測コードを Claude Code に渡して、設置から公開・確認まで任せました。そのとき、次の 2 つのことが分かりました。

### テーマ付属の設定は古くて動かないことがある {#old-theme-setting}

このブログのテーマ（minima 2.5）には、もともと Google アナリティクスの設定欄が用意されています。ところが Claude Code に調べてもらうと、中身が **終了した古い方式（ユニバーサル アナリティクス）用のコード** で、GA4 の測定 ID を入れても動かないことが分かりました。

そこで、テーマ付属の古いコードは使わずに、`<head>` のファイルに Google の計測コードと同じ GA4 用のコードを入れ、測定 ID だけを設定ファイル（`_config.yml`）に書く形にしてもらいました。**古いテーマやプラグインを使っている場合は、GA4 に対応しているか** を確かめておくと安心です。

### プライバシーポリシーに書くのが決まり {#privacy-policy}

Google アナリティクスの利用規約では、**サイトで Google アナリティクスを使っていること** と、データがどう集められ処理されるかを、サイトに書いて知らせることが求められています。

このブログでも、[プライバシーポリシー]({{ "/privacy/" | relative_url }}) に「Google アナリティクスを使っていること」「Cookie を使っていること」「Cookie を無効にすれば集めるのを断れること」を書き足しました。

## 計測できているか確かめる {#check-tracking}

### リアルタイムで自分のアクセスを見る {#realtime}

設定が終わったら、自分のブログを開いてから、Google アナリティクスの **レポート → リアルタイム** を開きます。リアルタイムのレポートには **過去 30 分間** のアクセスが出るので、ここに自分のアクセスが映れば成功です。

私の場合、設定してすぐに見たときはまだ何も映っていませんでした。少し時間をおいてもう一度見ると、リアルタイムのレポートにアクセスが映り、ちゃんと計測できていることが確かめられました。すぐに映らなくても、少し待ってから見直してみてください。

### 「No data received from your website yet.」と出ても慌てない {#no-data-yet}

設定してすぐスマホのアプリを開くと、ホーム画面に **「No data received from your website yet.」**（ウェブサイトからデータをまだ受信していません）と表示されました。

この表示は、設定した直後によく出るものです。Google のヘルプによると、データの収集が始まるまでに 30 分ほどかかることがあり、ふだんのレポートに数字がそろうまでには **24〜48 時間** かかることがあります。まずはリアルタイムのレポートで確かめて、ホーム画面は 1〜2 日待ってから見るのがおすすめです。

## 最初に覚えたい基本の用語 {#basic-terms}

レポートには数字がたくさん並びますが、最初はこの表の言葉が分かれば十分です。

| 用語 | 意味 |
|---|---|
| ユーザー（アクティブ ユーザー） | 来てくれた **人の数**。期間内に同じ人が何回来ても 1 人と数える（同じ端末・ブラウザの場合） |
| 新規ユーザー | 初めて来た人の数 |
| セッション | **訪問の回数**。1 人が朝と夜に来れば 2 セッション |
| 表示回数 | ページが **見られた回数**（ページビュー）。同じページを何度も見ても、その分数える |
| エンゲージメント率 | 「ちゃんと読まれた訪問」の割合。10 秒以上いた、2 ページ以上見た、などの訪問を「エンゲージメントのあったセッション」と数える |
| 直帰率 | エンゲージメント率の反対。すぐ帰ってしまった訪問の割合 |
| イベント | ページを見た、スクロールした、リンクを押した、などの **行動の記録**。GA4 はすべてをイベントとして数える |
| キーイベント | イベントのうち、特に大事なものとして印を付けたもの（以前は「コンバージョン」と呼ばれていた） |

ブログで最初に見るなら、**ユーザー（何人来たか）** と **表示回数（何回読まれたか）** の 2 つで十分です。

### どこから来たか（流入元）の見方 {#channels}

**レポート → 集客 → トラフィック獲得** では、訪問がどこから来たかが分かります。よく出てくる名前は次のとおりです。

| 表示 | 意味 |
|---|---|
| Organic Search | Google などの **検索結果**（広告ではない部分）から来た |
| Direct | URL を直接入力した、ブックマークから来た、など |
| Referral | **ほかのサイトのリンク** から来た |
| Organic Social | X（旧 Twitter）などの **SNS** から来た |

ブログを検索で読んでもらいたいなら、**Organic Search** が増えているかを見ていくと、検索向けの工夫が効いているかの目安になります。

### 記事ごとの閲覧数の見方 {#pages-report}

どの記事がよく読まれているかは、**レポート → エンゲージメント → ページとスクリーン** で見られます。記事のタイトルごとに表示回数が並ぶので、よく読まれている記事のテーマを次の記事選びに使えます。

## 自分のアクセスを数えないようにする {#exclude-own-visits}

自分で何度もブログを開くと、そのアクセスも数えられてしまいます。記事の確認で自分のブログをよく開く人は、数字が実際より多めに出ます。

Google アナリティクスには、**特定の IP アドレス（ネットの住所のようなもの）からのアクセスを除く** 機能があります（無料）。

1. **管理 → データストリーム → 作ったストリーム → タグ設定を行う → すべて表示 → 内部トラフィックの定義** で、自宅の IP アドレスを登録する
2. **管理 → データフィルタ** で「内部トラフィック」のフィルタを **有効** にする

注意点もあります。

- **有効にすると、除いたデータはあとから戻せません。** Google も、まず「テスト」の状態で試すことをすすめています。
- スマホの回線などは IP アドレスが変わりやすいので、自宅の回線以外では除ききれないことがあります。

ブログを始めたばかりで数字が少ないうちは、「自分の分も入っている」と分かったうえで見るだけでも十分です。

## スマホでも見られる {#mobile}

Google アナリティクスには、iPhone・Android 向けの **公式アプリ** があり、外出先でも数字を確かめられます。

ただ、私のスマホではアプリが **英語の表示で、使いにくい** と感じました。英語が苦手な人は、スマホのブラウザで [analytics.google.com](https://analytics.google.com/) を開くのも手です。

## よくある質問 {#faq}

### Google アナリティクスは本当に無料ですか？ {#faq-free}

通常版は無料です。有料版の「Google アナリティクス 360」もありますが、大規模なサイト向けで、個人のブログには必要ありません。

### 設定したのにデータが出ません {#faq-no-data}

ふだんのレポートに数字が出るまでは、24〜48 時間かかることがあります。まずは **リアルタイム** のレポートで、自分のアクセスが映るかを確かめてください。それでも何も出ない場合は、計測コードの測定 ID が合っているか、ブログのすべてのページに入っているかを確認します。広告ブロッカーなどを入れたブラウザでは、計測が止められることもあるので、別のブラウザでも試してみてください。

### Search Console とどちらを見ればいいですか？ {#faq-which}

両方です。**検索でどんな言葉で表示されたか** は Search Console、**来た人がどの記事を読んだか** はアナリティクスで分かります。2 つは無料で連携もでき、連携するとアナリティクスの中で検索の言葉も見られるようになります（連携後、レポートの「ライブラリ」で Search Console のコレクションを公開すると、左のメニューに表示されます）。

### プライバシーポリシーは必要ですか？ {#faq-privacy}

必要です。Google アナリティクスの利用規約で、Google アナリティクスを使っていることをサイトで知らせるよう決められています。将来 Google AdSense などの広告を入れる場合も、プライバシーポリシーは必要になります。

## まとめ {#summary}

- ブログの閲覧数は、**Google アナリティクス（無料）** を入れると分かる
- 登録は **アカウント ＞ プロパティ ＞ データストリーム** の順に作り、最後に出る **測定 ID（G- で始まる番号）** をブログに入れる
- 入れたら **リアルタイム** のレポートで確かめる。ふだんのレポートは 1〜2 日待つ
- 最初は **ユーザー** と **表示回数**、慣れたら **流入元** と **記事ごとの表示回数** を見る
- **プライバシーポリシー** に、Google アナリティクスを使っていることを書く

閲覧数が見えるようになったので、これからは「どの記事が読まれているか」を見ながら、次に書く記事を考えていこうと思います。

AI まわりの用語が分からない人は、[AIの基本用語をやさしく解説]({{ "/posts/ai-basic-terms/" | relative_url }}) もどうぞ。このブログの作り方は [Claude Codeでブログを作る方法]({{ "/posts/claude-code-github-pages-blog/" | relative_url }}) で紹介しています。
