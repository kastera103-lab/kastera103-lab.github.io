「モデル」「トークン」「コンテキスト」……。AI を使い始めると、説明なしに出てくる言葉がたくさんあります。

私も AI の知識はほとんどないまま、Claude Code（AI に PC の中で作業してもらうツール）を使い始めました。この記事では、**使いながら「これはこういう意味だったのか」と分かった AI の基本用語** を、初心者の目線でまとめます。

**この記事で分かること**

- 生成 AI・LLM・モデルとは何か
- 料金や使える量に関わる「トークン」とは何か
- AI が長い会話で前の内容を忘れやすくなる理由（コンテキスト）と、`/compact` と `/clear` の違い
- AI がもっともらしい間違いを言う「ハルシネーション」と、その防ぎ方
- 番外編：外出先からスマホで家の PC の AI に作業させる方法

> 情報は 2026年10月時点のものです。例として、私が使っている Anthropic 社の AI「Claude」の公式ドキュメントをもとに説明しています。

## まずは全体像：生成 AI・LLM・モデル {#overview}

### 生成 AI とは {#generative-ai}

**文章・画像・音声などを新しく作り出す AI** のことです。質問に答えたり、文章を書いたり、絵を描いたりできます。ChatGPT や Claude、画像生成 AI などがこれにあたります。

### LLM（大規模言語モデル）とは {#llm}

LLM は Large Language Model の略で、日本語では **大規模言語モデル** といいます。

大量の文章を学習して、**「この続きに来そうな言葉」を予測しながら文章を作る** 仕組みの AI です。会話できる AI の中心にあるのがこの LLM です。

### モデルとは {#model}

**AI の「頭脳」そのもの** のことです。同じ会社の AI でも、性能や速さ・料金が違うモデルがいくつか用意されています。

たとえば Claude には、2026年10月時点で次のようなモデルがあります。

| モデル | 特徴（公式の説明をもとに要約） |
|---|---|
| Fable | 難しい推論や、長時間かかる作業向け。返事は遅め |
| Opus | 長時間のコーディングや知的作業向け |
| Sonnet | 速さと賢さのバランスが良い |
| Haiku | 最も速い。大量の簡単な作業向け |

賢いモデルほど料金が高く、返事も遅くなる傾向があります。Claude Code では `/model` と入力すると、使うモデルを切り替えられます。

**使ってみて分かったこと**：正直に言うと、私はモデルについて「AI の種類みたいなもの」とざっくりとしか知りませんでした。**モデルごとに得意な用途がある** と知ったのは、つい最近です。Claude Code の料金を抑えるコツを書いた公式ドキュメントでも、たいていのコーディングは Sonnet で十分で、Opus は複雑な設計判断や何段階もの推論が必要なときに、と案内されています。

## トークン：AI が文章を数える単位 {#token}

**トークン** は、AI が文章を処理するときの単位です。AI は文章を「トークン」という細かいかけらに分けて読み書きしています。1 トークンは、だいたい単語や文字の一部くらいの大きさです。

トークンが大事なのは、次の 2 つに関わるからです。

- **料金**：API（プログラムから AI を使う方法）では、読ませたトークンと書かせたトークンの量で料金が決まります。料金表は「100 万トークンあたり何ドル」という形で書かれています。
- **使える量**：Claude の有料プランは定額ですが、一定時間に使える量に上限があります。長い会話や大きなファイルを読ませる作業ほど、その上限に早く近づきます。

**使ってみて分かったこと**：Claude Code は、こちらが送った一言だけでなく、**それまでの会話や読んだファイルの内容もまとめて** 毎回 AI に送っています。だから同じ一言でも、長い会話の途中だと多くのトークンを使います。Claude Code では `/usage` と入力すると、使った量を確認できます。

## コンテキスト：AI が一度に覚えておける範囲 {#context}

**コンテキスト**（コンテキストウィンドウ）は、**AI が返事を作るときに参照できる文章の全体** のことです。公式ドキュメントでは、AI の「作業用の記憶（working memory）」と説明されています。

ここには、今の会話の履歴、読ませたファイル、AI 自身の返事などがすべて入ります。大きさはトークンで表され、最近の Claude のモデルでは 100 万トークン（英語ならおよそ 55 万語分。日本語では数え方が違うので、あくまで目安です）まで入ります。

### 長い会話で AI が忘れっぽくなる理由 {#context-rot}

100 万トークンはとても大きいのですが、公式ドキュメントによると、**中身が増えるほど正確さや思い出す力が落ちていく** そうです（context rot と呼ばれます）。たくさん入れればよいわけではなく、何を入れておくかが大事です。

そこで Claude Code には、会話を整理するコマンドがあります。

| コマンド | すること |
|---|---|
| `/compact` | それまでの会話を要約して、中身を軽くしてから続ける |
| `/clear` | 会話をリセットして、新しく始める |
| `/context` | 今コンテキストに何が入っていて、どれくらい使っているかを見る |

**使ってみて分かったこと**：Claude Code は作業の区切りで「`/compact` をおすすめします」とよく言ってきます。最初は `/compact` と `/clear` の違いが分からず、「全部消してすっきりする `/clear` を使えばいいのでは？」と思っていました。

違いは、**それまでの話を AI が覚えているかどうか** です。

- `/compact`：要約を残すので、同じ作業の続きができる
- `/clear`：会話の中身は残らないので、まったく別の作業を始めるとき向け（`CLAUDE.md` に書いたことは、また読み込まれます）

同じ作業を続けたいのに `/clear` を使うと、AI はそれまでの話を全部忘れてしまいます。`/compact` は、**会話が長くなりすぎて AI の作業の質が落ちるのを防ぎつつ、続きをするため** のものだったのです。

ただし、要約すると細かい内容は抜け落ちます。私は、大事な決めごとや進み具合をファイル（`CLAUDE.md` や進捗メモ）に書いてもらっています。こうすると、要約したり会話をリセットしたりした後でも、AI がそれを読んで続きから作業できます。

## 知識のカットオフ：AI が知っているのは「ある時点まで」 {#knowledge-cutoff}

AI のモデルは、ある時点までの情報で学習しています。その時点を **知識のカットオフ**（学習データの期限）といいます。

たとえば 2026年10月時点の Claude のモデルは、2026年6月ごろまでの情報で学習しています（公式のモデル一覧より）。

それより後に起きたことや、新しく出たサービスの情報は、基本的に知りません。新しい情報が必要なときは、AI に Web で調べてもらうか、自分で公式サイトを確かめる必要があります。

## ハルシネーション：AI のもっともらしい間違い {#hallucination}

**ハルシネーション** は、AI が **事実と違うことを、もっともらしく自信ありげに言ってしまう** ことです。英語で「幻覚」という意味です。

公式ドキュメントでも、最先端のモデルでも起こりうると書かれています。対策をすれば減らせますが、ゼロにはできません。

**使ってみて分かったこと**：実はこのブログの記事を作ったときにも起きました。前の記事の下書きに、AI が「日本語の見出しには自動でリンク用の名前が付かない」と書いていました。でも、別の AI にチェックさせて調べ直したところ、**実際には付く** ことが分かりました。AI が自分用のメモに書いていた内容が、そもそも間違っていたのです。

### ハルシネーションを減らすコツ {#reduce-hallucination}

- **「分からなければ分からないと言って」と伝える**：無理に答えを作りにくくなり、間違いが減ります。
- **「出典（公式サイトなど）を確認して」と頼む**：根拠を確かめさせると、間違いに気づきやすくなります。
- **別の AI にチェックさせる**：書いた AI とは別の AI に見直させると、思い込みに引きずられにくくなります。
- **大事なことは自分でも確かめる**：お金・契約・健康などに関わることは特に注意しましょう。

## プロンプト：AI への頼み方 {#prompt}

**プロンプト** は、AI に送る指示や質問の文章のことです。同じ AI でも、プロンプトの書き方で結果が大きく変わります。

コツは「何を・どうなったら完成か」を具体的に書くことです。詳しくは [Claude Codeの使い方]({{ "/posts/claude-code-getting-started/" | relative_url }}#tips) の「Claude Code をうまく使う5つのコツ」で紹介しています。

## エージェントとサブエージェント {#agent}

### AI エージェントとは {#ai-agent}

**AI エージェント** は、答えを返すだけでなく、**自分で手順を考えて、道具（ツール）を使いながら作業を進める AI** のことです。

チャットの AI は答えを画面に出すだけですが、Claude Code のような AI エージェントは、ファイルを読む・書く・コマンドを実行する・結果を見て直す、といったことを自分で繰り返します。

### サブエージェントとは {#subagent}

**サブエージェント** は、メインの AI が仕事の一部を任せる、**別の AI アシスタント** です。公式ドキュメントによると、サブエージェントは **それぞれ自分専用のコンテキストを持って** 動きます。

メインの会話とは別の頭で作業するので、メインの会話が長くならずに済みます。前の話を知らない状態で見直すので、思い込みに気づきやすいという良さもあります。上で書いたハルシネーションも、このサブエージェントにチェックさせたことで見つかりました。

## 番外編：外出先からスマホで家の PC の AI に作業させる {#remote-control}

最近覚えて、よく使うようになったのが Claude Code の **Remote Control（リモートコントロール）** です。

家の PC で動いている Claude Code の画面で `/remote-control`（短く `/rc`）と入力すると、**スマホの Claude アプリやブラウザから、同じ会話の続きを操作できる** ようになります。

作業はスマホではなく、**家の PC の中でそのまま行われます**。外出先から「この記事の続きを書いて」と頼むと、家のデスクトップにあるファイルを AI が読み書きしてくれます。

**使ってみて分かったこと**：最近知ってから、かなり多用しています。外出先からでも、スマホで家のデスクトップ上の作業を進められるのがとても便利です。

注意点もあります。

- Claude の有料プラン（Pro / Max など）が必要です（API キーでは使えません）
- 家の PC と、Claude Code を起動している画面は開いたままにしておく必要があります（閉じると、スマホからつながらなくなります。PC のスリープや通信切れなら、PC が復帰すると自動でつながり直します）

## よくある質問 {#faq}

### AI の仕組みを理解していないと使えませんか？ {#faq-understand}

使えます。私も仕組みはほとんど知らないまま使い始めました。ただ、この記事の「トークン」「コンテキスト」「ハルシネーション」の 3 つを知っておくと、次のような良いことがあり、失敗が減ります。

- 料金や使える量の感覚がつかめる
- 長い会話で AI の調子が悪くなる理由が分かる
- AI の答えをうのみにしなくなる

### /compact と /clear はどちらを使えばいいですか？ {#faq-compact-clear}

同じ作業を続けるなら `/compact`、まったく別の作業を始めるなら `/clear` です。`/compact` は会話を要約して残し、`/clear` は会話をすべてリセットします。

### どのモデルを選べばいいですか？ {#faq-which-model}

迷ったら、そのツールの標準のモデルのままで大丈夫です。慣れてきたら、簡単な作業は速いモデル、難しい作業は賢いモデル、と使い分けると、待ち時間や使う量を節約できます。

### AI の答えはどこまで信じていいですか？ {#faq-trust}

「たたき台」として使うのがおすすめです。特に、数字・日付・料金・最新情報は間違えやすいので、公式の情報で確かめましょう。

## まとめ {#summary}

- **LLM** は、続きの言葉を予測して文章を作る AI。その「頭脳」にあたるのが **モデル**
- **トークン** は AI が文章を数える単位で、料金や使える量に関わる
- **コンテキスト** は AI が一度に参照できる範囲。長くなると正確さが落ちるので、続けるなら `/compact`、別の作業なら `/clear` で整理する
- **ハルシネーション** は AI のもっともらしい間違い。出典の確認や、別の AI のチェックで減らせる
- **AI エージェント** は、ツールを使いながら自分で作業を進める AI
